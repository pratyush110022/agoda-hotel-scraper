# Agoda Hotel Scraper

Python scraper for Agoda hotel search results, with sample data where available.

## Contents

- `Agoda Scraper.py` — scraper source code
- `requirements.txt` — Python dependencies
- `sample_data/` — sample output/data files, when available

## Setup

1. Install Python 3.10 or a compatible version.
2. Create and activate a virtual environment.
3. Install dependencies:

   ``bash
   pip install -r requirements.txt
   ``

4. Review the configuration values near the top of the Python script before running it.
